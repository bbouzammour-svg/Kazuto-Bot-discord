# Kazuto-Bot-discord
Utility Bot Created By Nori Development

# A lightweight, open-source Discord bot built with Node.js to provide server management, automated moderation tools, and event logging for online communities.

Features
Automated user moderation and restriction commands

Fast and responsive Discord API interaction handling

Modular, lightweight codebase designed for easy customization

Setup
Download the project as a .zip file and extract it to your computer.

Open the extracted folder directly in your code editor (such as VS Code).
